Minebot library

Simple Python automation library.

install

- install others library
- pip install pyautogui
- pip install pydirectinput
- pip install pillow
- pip install opencv-python
- pip install git+https://github.com/Andreaswinter2012/minebot.git and install Git for windows (winget install Git.Git -h)

Example 1

import minebot
import time

time.sleep(5)

start = True

while True:
    while start:
        minebot.removeblock(3)

        if minebot.chat("r", "stop.png"):
            start = False
            break

    if minebot.chat("r", "start.png"):
        start = True

Example 2

import minebot
import time

count = 0
countin = int(input("count: "))

time.sleep(5)

while count < countin:
    count += 1
    minebot.removeblock(1)
    time.sleep(1.5)

minebot.walk("d", 1)
minebot.select("2")
minebot.drop("all")
minebot.walk("a", 1)
minebot.select("1")

Example 3

import minebot
import time

count = 0
countin = int(input("count: "))

time.sleep(5)

while count < countin:
    count += 1
    minebot.removeblock(1.2)
    minebot.walk("w", 0.2)

Commands

removeblock(time)
walk(key, time)
select(slot)
drop(mode)
chat(mode, image)
